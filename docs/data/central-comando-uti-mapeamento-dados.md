# Dados Necessários — UTI (v1)

- **Pacientes** — Nome, Idade, Gênero
- **Diagnóstico** — Motivo da internação
- **Sinais Vitais** — FR, SpO₂, PAS, FC, Temperatura
- **Nível de Consciência** — selecionado pelo médico/enfermeiro na aplicação (Alerta, Confuso, Responde à Dor, Inconsciente). Campos: internação, data/hora da avaliação, valor selecionado, quem avaliou
- **Internações** — Registros de internações dos pacientes
- **Leitos** — Registros dos leitos das internações
- **Exames** — Resultados/exames solicitados
- **Prontuários** — Prontuário do paciente
- **Alertas** — Tabela para registrar histórico de alertas
